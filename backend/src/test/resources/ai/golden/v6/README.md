# Golden AI dataset v6

v6 inherits the v2 base, v4 rubric alternatives, and v5 input contract. Its
only case change is the versioned Case 5 rubric override. v2/v4/v5 resources
and prior reports remain historical evidence under their own identities.

Case 5 permits PARTIAL for the learner's stated wrist-extensor paralysis while
requiring the wrong median-nerve attribution to remain an explicit misconception.
CORRECT is forbidden. Feedback must identify the median/radial nerve gap and
explain it in student-friendly language. The correct nerve cannot be credited
as learner knowledge merely because it appears in the question or source.

This rubric does not automatically award PARTIAL for every wrong medical term.
The independent correct component, incorrect anatomical identity, source
support, and actual feedback require human semantic review under ADR-0011.
