# Golden AI dataset v5

v5 inherits v2 cases and the v4 rubric overlay, then applies the versioned
wrong-reasoning input contract. Historical v1-v4 resources remain unchanged
and can be loaded explicitly. Previous qualification results are not regraded.

The wrong-reasoning case now supplies three indexed propositions: radial nerve
supply to wrist extensors, radial nerve injury eliminating wrist extension, and
loss of wrist extension producing wrist drop. Its expected answer and mechanism
rubric use the same source-supported functional loss relationship. The original
synthetic source evidence is retained verbatim; no denervation sentence or
external knowledge is added. Literal denervation is not a requirement in v5.

Required missing-concept evidence belongs in missingConcepts. Correct concepts
and feedback cannot supply it. Historical input/rubric contracts are preserved;
the evaluator's previous cross-field false positives are corrected, not retained
as a historical qualification policy. Human educational review remains required.
